# Mia_Birthday

MIA'S BIRTHDAY WEBSITE — QUICK START

1. In VS Code, right-click index.html and choose "Open with Live Server" if you have the Live Server extension.
   Or double-click index.html in File Explorer to open it directly in your browser.

EDITING THE LETTER
Open index.html and edit the Afrikaans paragraphs inside <article class="paper">.
Save and refresh the browser to see your changes.

FILES
- index.html: page structure and letter
- style.css: colors, layout and animations
- script.js: dodging button, letter reveal and confetti
